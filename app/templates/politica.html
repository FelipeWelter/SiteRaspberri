Política de Privacidade

Entenda como seus dados são coletados, utilizados e protegidos.
Última atualização: 26/11/2025

Esta Política de Privacidade descreve como o SISTEMA DE CONTROLE DE MATERIAL, desenvolvido e mantido por Felipe Ribeiro S. Welter, coleta, utiliza, armazena, protege e trata os dados dos usuários durante o uso da plataforma.

Ao acessar ou utilizar o sistema, o usuário declara ter lido, compreendido e concordado integralmente com esta Política de Privacidade.

1. Introdução

Esta Política tem como objetivo informar, de forma clara e transparente, quais dados são tratados, para quais finalidades e quais medidas de segurança são adotadas para proteção das informações.

2. Dados Coletados

O sistema pode coletar e armazenar os seguintes tipos de dados:

2.1 Dados fornecidos pelo usuário
  • Nome completo;
  • Identificação (RG, identidade militar ou similar);
  • Login e senha;
  • Informações inseridas em formulários internos do sistema.
2.2 Dados coletados automaticamente
  • Endereço IP;
  • Navegador utilizado;
  • Datas e horários de acesso;
  • Ações realizadas no sistema (logs);
  • Informações de uso e comportamento dentro da plataforma.
2.3 Dados sensíveis

O sistema não coleta, de forma intencional, dados sensíveis como informações de saúde, crenças religiosas, orientação sexual ou qualquer outra categoria protegida, exceto se houver exigência específica de normas internas da organização responsável pelo sistema.

3. Finalidades do Tratamento de Dados

Os dados coletados são utilizados para:

  • Gerenciar contas de usuários e permissões de acesso;
  • Registrar ações para fins de auditoria e segurança;
  • Permitir o funcionamento adequado das funcionalidades do sistema;
  • Controlar o acesso, movimentação e registro de materiais;
  • Melhorar a estabilidade, performance e integridade da plataforma;
  • Cumprir obrigações legais, administrativas ou de segurança institucional.
4. Compartilhamento de Dados

Os dados poderão ser compartilhados somente nas seguintes situações:

  • Para atendimento a determinações legais, judiciais ou administrativas;
  • Com setores internos autorizados da organização responsável pelo sistema;
  • Para auditorias internas ou externas, quando aplicável;
  • Quando estritamente necessário para manutenção, suporte técnico ou segurança do sistema.

Os dados não serão vendidos, alugados ou repassados a terceiros não autorizados.

5. Armazenamento e Segurança dos Dados

São adotadas medidas técnicas e administrativas para proteção dos dados pessoais, tais como:

  • Armazenamento em base de dados protegida;
  • Controle de permissões de acesso por perfil de usuário;
  • Registro de logs de acesso e ações relevantes;
  • Criptografia de senhas no banco de dados;
  • Atualizações e correções de segurança sempre que possível.

Apesar dos esforços, nenhum sistema é completamente invulnerável, e não é possível garantir segurança absoluta contra todos os tipos de incidentes.

6. Retenção dos Dados

Os dados serão armazenados pelo tempo necessário para:

  • Manter o funcionamento regular do sistema;
  • Atender aos objetivos de controle e registro de materiais;
  • Cumprir obrigações legais e regulatórias.

Mesmo após o encerramento de uma conta, alguns registros e logs poderão ser mantidos para fins de auditoria, segurança e cumprimento de obrigações legais.

7. Direitos do Usuário

O usuário possui, entre outros, os seguintes direitos em relação aos seus dados pessoais:

  • Solicitar acesso às informações que lhe dizem respeito;
  • Requerer a correção de dados incompletos, inexatos ou desatualizados;
  • Solicitar esclarecimentos sobre a forma de tratamento dos dados;
  • Requerer a exclusão da conta, quando permitido pela organização, observadas as obrigações legais e de auditoria.

Alguns pedidos poderão não ser atendidos integralmente quando houver necessidade de preservação de registros por motivos legais ou institucionais.

8. Uso de Cookies

O sistema pode utilizar cookies estritamente necessários para:

  • Manter sessões de login ativas;
  • Garantir funcionalidades essenciais de navegação;
  • Melhorar a experiência de uso dentro da própria aplicação.

Não são utilizados cookies para fins de publicidade ou rastreamento externo a este sistema.

9. Alterações nesta Política de Privacidade

Esta Política poderá ser atualizada periodicamente, para refletir melhorias no sistema ou adequações a normas internas e legislações aplicáveis.

Recomenda-se que o usuário consulte esta página regularmente. O uso contínuo do sistema após alterações será interpretado como concordância com a versão atualizada.
